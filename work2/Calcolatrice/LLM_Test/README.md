## Struttura del progetto

- `scripts`: Contiene gli script per generare i test con i diversi modelli.
- `CalcolatricePrompt`: Contiene i prompt per tutti gli scenari per cui abbiamo generato i test nella cartella input. La cartella output invece contiene i test generati dagli LLM.

## Results
- `risultati`: Contiene i risultati per ogni singolo scenario.
