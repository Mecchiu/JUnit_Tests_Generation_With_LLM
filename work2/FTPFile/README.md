# FTPFile

## Descrizione
Questa directory contiene tutto quel che riguarda la classe **FTPFile**, per cui si vogliono generare test con LLM.

---

## Struttura della directory
Di seguito sono elencate tutte le sottocartelle e i file contenuti, con il loro ruolo specifico:

### 1. `FTPFileSourceCode`
Questa directory contiene il codice sorgente del progetto. All'interno si possono trovare anche diverse cartelle che indicano diversi scenari se ce ne sono.


---

### 2. `ProgettoFTPFile`
Progetto Maven per includere tutte le dipendenze e configurare un ambiente di esecuzione che ci permetterà poi di eseguire i test e generare i report con JaCoCo.


---

### 3. `LLM_Test`
Contiene tutte le risorse utili per la generazione dei test con i Large Language Models.


---

### 4. `EvoSuiteTest`
Contiene i test generati da EvoSuite e i rispettivi report di copertura divisi in 3 livelli.


---

### 5. `RandoopTest`
Contiene i test generati da Randoop e i rispettivi report di copertura divisi in 3 livelli.


---

### 6. `StudentTest`
Contiene i test generati manualmente da studenti e rispettivi report.

---
