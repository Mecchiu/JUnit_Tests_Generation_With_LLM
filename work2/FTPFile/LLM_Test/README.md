## Struttura del progetto

- `scripts`: Contiene gli script per generare i test con i diversi modelli.
- `FTPFilePrompt`: Contiene i prompt per tutti gli scenari per cui abbiamo generato i test nella cartella input. Nella cartella output invece ci sono tutti i test generati con LLM.

## Results
- `risultati`: Contiene i risultati per ogni singolo scenario.
