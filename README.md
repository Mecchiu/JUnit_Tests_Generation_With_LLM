Questo progetto è strutturato in due cartelle principali, work1 e work2, che rappresentano le due fasi principali della sperimentazione della tesi.

## Descrizione

- `work1`: Dedicata alla riesecuzione dell'esperimento originale analizzato nell'articolo studiato, con la rigenerazione ed esecuzione dei test per i dataset HumanEval e SF110.
- `work2`: Dedicata alla sperimentazione successiva allo studio, con la generazione ed esecuzione dei test su un insieme di classi selezionate (Calcolatrice, FTPFile, HSLColor, OutputFormat e TimeStamp).
